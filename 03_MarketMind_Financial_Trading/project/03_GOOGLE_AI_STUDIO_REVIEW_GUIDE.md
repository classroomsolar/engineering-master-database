For a privacy-minimising external Gemini/AI Studio code audit, use the accompanying standalone `MarketMind_AI_Studio_SAFE_CODE_REVIEW_2026-10-25.zip` (no raw broker source files and no actual HTML containing position data). It contains generic Python calculation engines, synthetic tests, analysis plan and an audit prompt. The owner decides whether to share additional private documents under the actual provider's current data handling, training and billing terms.

To test entire website interface visually, the full private HTML is required but contains dated user investment data. First produce a safe synthetic-only duplicate using placeholders (preserve source code logic and UI structure) or run tests in a private owner-controlled environment. Do NOT label synthetic screenshots as the user's current holdings.

2. Check all issuer and market-data assertions against dated, official records and source freshness; require defensible adjustment policies for splits/dividends/delistings.

4. Critique mobile UX and accessibility; preserve original implementation, do not copy proprietary Jimo or Awwwards designs/code.
5. Provide test cases, risk ranking, issue IDs, independent counterexamples, and actionable fixes. Do not overwrite original files or make live trades.
